# ETH1003｜ETH 策略與 Bitget 網頁控制台

這是獨立專案，沒有修改原本的 EasiCoin 正式交易程式。Bitget 對接以使用者驗證過的 [`s300` main](https://github.com/chenyu951216-afk/s300) `09656136` 為基準；搬入的核心在 `eth1003/exchange/bitget.py`。差異與依賴見 [S300_DEPENDENCY_MAP.md](S300_DEPENDENCY_MAP.md)。

## 目前能做什麼

- 網頁操作：建立管理密碼、填入 Bitget Demo／Live 金鑰、只讀診斷、本機模擬測試、固定歷史重播、**Demo 最小單開平倉驗證**、檢查策略訊號、預覽決策、啟停下單和自動檢查、查詢本地帳本及交易所、明確接管既有 ETH 多單、人工部分／全部平倉、取消委託、修改 Classic 限價單、另掛或取消本程式建立的交易所止盈止損。
- 電腦與手機自適應頁面，依功能分頁。預設只在本機開啟；同區域網路可使用 `--lan` HTTPS 模式。
- 開倉前檢查商品規格、價格與數量步進、最低金額、倉位階梯、即時報價、可用保證金和既有委託／持倉。商品與該名目階梯都必須支援 **150 倍**；S300 `prepare` 設定單向／全倉／150 倍後再回讀，任何一項不符即停止下單。
- `clientOid` 先寫入 SQLite，再送金融 POST。逾時或伺服器錯誤後不盲目重送；訂單接收、成交量、持倉、交易所止盈止損均可回讀。
- 程式啟動時交易與自動檢查都預設關閉。網站上需先登入、填入帳戶、輸入模式對應啟用文字，才能讓自動執行或人工交易操作送單。Demo 與 Live 使用不同帳本。API 金鑰只留在程式記憶體，重啟須重新填入；不寫入 Git 或 SQLite。

## 策略規則與回測對齊

1. 訊號資料：Binance ETHUSDT 永續自 2020 起的完整 1 小時收盤價。只用前一根已完成 K 線計算 `EMA12 > EMA720`。不回填錯過的小時價格下單。
2. 只做多或空手。最多一筆本程式擁有的 ETH 多單，不做空、不疊倉。EMA 反轉時以 S300 的只減倉市價單平實際持倉。
3. 開倉名目目標為 `當時 Bitget 帳戶權益 × 1.35% × 150`，先依回測規則把 ETH 數量向下取整至 **0.01 ETH**，再依 Bitget 商品步進檢查。交易所對接不會再次乘上 150。
4. 回測沒有獨立固定止盈、停損。網頁提供人工新增交易所 TP／SL 功能，但使用它會改變原策略，**不能再用原回測獲利代表該變體**。
5. 資金以交易所實際權益計算。每月入金不由程式自動轉帳；使用者實際投入多少，權益便反映多少。歷史報告的每月 300 U 僅是比較假設，不把入金算交易獲利。

歷史代理結果：2020–2026/09、100 U 起步、假設每月入金 300 U，總投入 22,900 U、期末 158,130.82 U、**扣入金交易淨利 135,230.82 U**；完成 121 筆、勝率 23.97%、完整週期資金流調整最大回撤 67.85%。2022 年交易淨虧 7,806.51 U。這組尺寸在同段已知歷史上選出，尚未經未見資料驗收。Freqtrade 證實交易進出場時點；150x 全程、入金與 Cross 風控由 Python 帳戶重播。回測並不是 Bitget 實際成交、實際強平保證或未來收入。

網站「歷史研究」分頁有年度表與可下載的逐日盈虧 CSV；原核對報告、Freqtrade 策略、重播報告、凍結行情與固定 1.35% 重播程式在 `research/`。可用 `py -3.14 research/replay_frozen.py` 重算這個固定方案，程式會對照已審核的期末金額與交易數；它不搜尋新參數。

## 在電腦開啟網站

需要 Python 3.11 以上。Windows 範例：

```powershell
py -3.14 -m pip install -e ".[test,backtest]"
py -3.14 -m eth1003.cli test
py -3.14 -m eth1003.cli web
```

在本機開啟 `http://127.0.0.1:8765/`。第一次先建立至少 12 字元的管理密碼。連接頁填入金鑰後，先使用「查公開 ETH 合約」與「檢查帳戶與報價」，再預覽決策。網頁上可分開啟用下單與自動檢查；只按「預覽」不會送金融 POST。

若要讓同一區域網路的手機查看，先在電腦完成管理密碼設定，再改以：

```powershell
py -3.14 -m eth1003.cli web --lan
```

程式顯示手機網址。`--lan` 產生本機自簽 HTTPS 憑證，手機第一次會提示憑證尚未受公認機構信任。手機與電腦須在同一網路，Windows 防火牆也須允許此服務。若要從外網安全存取，應另外配置受信任 HTTPS 網域／反向代理；不要以明文 HTTP 在外網輸入真實交易金鑰。程式重啟後連接金鑰與交易開關會清空，需要在網頁重新填入及啟用。

## 尚未聲稱的驗證

目前沒有使用者 Bitget Demo／Live 金鑰，因此**沒有對真實帳戶送單**、沒有交易所接單或實際成交證據。62 個自動測試覆蓋簽名、Demo 標頭、Classic／UTA、150 倍設置回讀、步進／階梯、POST 逾時不重送、委託／持倉／止盈止損回讀、只減倉平倉、網站授權、模擬開平倉全流程與策略訊號。公開 ETH 商品查詢目前顯示商品與約 200 U 名目階梯的上限均為 150 倍；實際帳戶仍必須走設定後回讀。若 Demo 驗證不能通過，網站會保持停止交易，不能視為已可正式交易。

Bitget 市價成交與 Binance 歷史下一小時開盤價不同；實際費率、Funding、滑價、維持保證金階梯以及極端行情會讓收益與回撤偏離歷史回測。詳細驗證邊界見 `research/reports/eth_freqtrade_1p35_validation_report.md`。
